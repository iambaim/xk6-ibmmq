## Reuse IBM MQ connections per VU

Set `MQ_CONNECTION_REUSE=true` to reuse one IBM MQ connection per virtual user
across sends, receives, and iterations. Existing scripts keep opening a new
connection for each operation unless they opt in.

Idle connections close after 30 seconds by default. Set
`MQ_CONNECTION_IDLE_TIMEOUT` to change that, or call `ibmmq.close()` to
disconnect the current VU. If a connection breaks, the next operation opens a
new one. Failed operations are not replayed in reuse mode.

Use the `ibmmq_connections` counter to count successful MQ connection opens
during VU iterations. It counts MQ handles, not TCP sockets.

`receive()` rejects invalid or all-zero message IDs before opening the queue
and checks for k6 cancellation between short MQ waits.

This is a source-only release. Build locally with the IBM MQ client installed;
the release does not ship executables or container images.
